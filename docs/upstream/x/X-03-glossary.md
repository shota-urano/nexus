## 1. 用語集の決まり

- 載せる語の範囲: 業務の言葉のうち意味がずれうるもの、機能名・画面名・エンティティ名に使うもの、配信元から引き継いだ言葉、略語。一般的な IT 用語は載せない。
- 足す・直す手順: 書類を書く RD-01 SH02 が足し、RD-01 SH01 が定義を確かめる。定義を変えるときは、その語を使っている書類を探して直す。
- 並べ方: 区分ごとに、読みの五十音順に並べる。英字の語は区分の先頭に置く。
