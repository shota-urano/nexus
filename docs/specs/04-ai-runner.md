# 04. AI Runner と記事の関係の判定 仕様

**親**: [`00-overview.md`](./00-overview.md) ｜ **担当**: Backend ｜ **範囲**: AI の呼び出し（M26）、待ち行列（M20）、AI Runner（M24）、記事の関係の判定（FN-002）、状態を返す API

設計の正本は `docs/upstream/` の上流工程の書類である。この仕様書は、DD-11 実装単位一覧が書き出した実装への引き渡しで、設計の中身を書き写さず、書類と節で指す。

## 1. 目的

AI を呼ぶ1か所（M26）と、DB の待ち行列を拾って動かす AI Runner を作り、記事の関係の判定（FN-002）を動かす。

## 2. 入出力

入力: `ai_run` の待ち。出力: `article_relation`、`ai_run` の結果、`getHealth` の応答。

## 3. 処理詳細

- DD-02 FN-002、3章 P06、P07。
- CLI の引数と設定と環境変数: DD-09 2.5（X-04 Q-082 の答え）。
- CLI の出来事の読み取り: DD-04 4.2。
- 渡す量の抑え方: DD-02 FN-002 手順 3（Q-086 の答え）。

## 4. 設定値・確定値

- 同時に 2 つ、1 回 5 分、自動の送り直しは 1 回（NFR-017）。
- 記事の関係の判定ではツールを使わせない（`--tools ""`）。
- CLI に `ANTHROPIC_` で始まる環境変数を渡さない（DD-09 2.5）。
- 案内は先頭 600 文字、合計 200,000 文字まで（Q-086 の答え）。

## 5. インターフェース

`getHealth`（DD-04）。IF-004（DD-04 4.2、DD-09 2.5）。

## 6. エラー処理

DD-06 E09〜E13、E17。

## 7. スコープ外
