## 1. 台帳の決まり

- 集める元: X-06 で採った書類の「上流との対応」の節と、DD-11 の行。
- 作り直す時機: 各工程のレビューの前（X-05）と、変更要求を承認する前（X-04）。作り直した日付を表の上に書く。
- 作り方: 機械で集める。道具は `dscheck x01` で、手で書き足さない。
- 対象にする要件の状態: RD-16 の状態が「承認」と「取り込み済み」の `REQ`。承認の前は「提案」も入れて集め、そのことを書く。
