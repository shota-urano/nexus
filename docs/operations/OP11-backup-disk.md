# OP11 別のディスクの保管、戻すとき、捨てるとき

バックアップ（私的な会話を含む）を置く別のディスクを、本人だけが読めるように保管し、戻し、捨てる（BD-11 7章、NFR-028、Q-064 の答え）。暗号化は求めない（Q-060 の答え）。

## きっかけ

- 別のディスクを初めてつなぐとき（OP01）。
- ディスクを替えるとき（壊れた、容量が足りない）。
- ディスクを捨てるとき。
- 写しを戻すとき（OP07）。

## 手順

### 保管するとき

1. 別のディスクは、Mac mini につないだままにする。持ち出さない。ほかの機器につながない。
2. 置き場所 `/Volumes/<ディスクの名前>/nexus-backup` の権限を `0700` にする（本人のユーザだけ）。

   ```sh
   mkdir -p "/Volumes/<ディスクの名前>/nexus-backup"
   chmod 0700 "/Volumes/<ディスクの名前>/nexus-backup"
   ```

3. ディスクの名前を `env` と launchd の設定の `NEXUS_BACKUP_DIR` に書く（OP01 の手順 6）。ディスクの名前は、名前を替えずに使い続ける。
4. Finder でディスクの「このボリューム上の所有権を無視」が切れていることを確かめる。入っていると、ほかのユーザからも写しが読める。

### 戻すとき

1. 写しは、Mac mini の本人のユーザの中だけで戻す。ほかのユーザや、ほかの機器で開かない。
2. ディスクを Mac mini から外して持ち出さない。つないだまま OP07 で戻す。

### ディスクを替えるとき

1. 新しいディスクを Mac mini につなぎ、「保管するとき」の手順 2 と 3 を行う。
2. launchd の設定を書き替えたときは、定期ジョブを読み込ませ直す。

   ```sh
   launchctl bootout gui/$(id -u)/jp.uslab.nexus.backup
   launchctl bootstrap gui/$(id -u) ~/Library/LaunchAgents/jp.uslab.nexus.backup.plist
   ```

3. 次の BAT-001 までは戻せる写しが無いので、OP08 で手で1回取る（BD-11 4章）。
4. 古いディスクは「捨てるとき」に従う。

### 捨てるとき

1. 捨てる前に中身を消す。ディスクユーティリティでディスクを消去する。

   ```sh
   diskutil list
   diskutil eraseDisk APFS Erased /dev/<ディスクの番号>
   ```

   番号を間違えると別のディスクを消すので、`diskutil list` の名前と大きさで確かめてから打つ。

2. 消したことを確かめてから捨てる。中身を消せない（壊れて読めない）ディスクは、壊してから捨てる。

## 確かめ方

- 置き場所の権限が本人のユーザだけである。

  ```sh
  ls -ld "/Volumes/<ディスクの名前>/nexus-backup"
  ls -l "/Volumes/<ディスクの名前>/nexus-backup/"
  ```

  フォルダが `drwx------`、写しが `-rw-------` で、持ち主が本人のユーザである。

- ほかのユーザからは読めない（運用の試験で確かめる。RD-15 AC27）。
- 捨てたディスクは、消去の後に `diskutil list` で中身の無いボリュームだけになっていた。
