# 08. ニュース（News Galaxy と記事の案内） 仕様

**親**: [`00-overview.md`](./00-overview.md) ｜ **担当**: Frontend ｜ **範囲**: 記事の図（FN-003）と記事の案内（FN-004）の API と画面（SCR-002、SCR-003）

設計の正本は `docs/upstream/` の上流工程の書類である。この仕様書は、DD-11 実装単位一覧が書き出した実装への引き渡しで、設計の中身を書き写さず、書類と節で指す。

## 1. 目的

選んだ日の記事の図と、記事の案内を、API と画面（M03、M08 のニュースの部品）で作る。

## 2. 入出力

入力: 日付、内容 ID。出力: DD-04 `getGalaxy`、`getArticle` の応答と画面。

## 3. 処理詳細

- DD-02 FN-003、FN-004。
- 図の部品: ADR-015（React Flow）。

## 4. 設定値・確定値

- 作り物の中心を置かず、選んだ記事を中心にする（RD-03 R04）。
- テーマの絞り込みは画面の中で行う（SCR-002-A03）。

## 5. インターフェース

DD-04 `getGalaxy`、`getArticle`。

## 6. エラー処理

MSG-001、MSG-002、MSG-003、MSG-019。DD-06 E01、E05、E08。

## 7. スコープ外

AI チャットを開く入口の中身（10-chat.md）。

## 9. 実装単位

- [x] [Backend] `getGalaxy` と `getArticle` を作る（FN-003、FN-004、DD-01 M15、DD-02 FN-003・FN-004）（se/08-news）
  - 受け入れ基準: DD-10 TC19、DD-10 TC20、DD-10 TC22、DD-10 TC23 が通る
- [x] [Frontend] News Galaxy と記事の案内の画面 M03 と、ニュースの表示部品 M08 を作る（SCR-002、SCR-003、ADR-015）（se/08-news）
  - 受け入れ基準: DD-10 TC21、DD-10 TC29 が通る
- [x] [Frontend] News Galaxy の上の帯の「AI に質問」（SCR-002-A05）と、記事の案内の「AI に質問」（SCR-003-A05）を押すと、その記事を対象（`kind: "article"` と内容 ID）に AI チャットの面 SCR-006（M06 の `ChatSheet`）を下から開く。記事の案内を全画面で開いたとき（`/news?article={contentId}`）も同じにする。今は道（M01）が `onAskAi` を渡しておらず、押しても何も起きない（BD-03 SCR-002-A05・SCR-003-A05・4章、DD-01 M01・M03・M06）（se/08-news-2）
  - 受け入れ基準: News Galaxy で記事を選び、記事の案内の「AI に質問」を押すと、AI チャットの面が開き、その面の質問の対象がその記事（`kind: "article"` とその記事の内容 ID）である; 上の帯の「AI に質問」を押すと、中心の記事を対象に同じ面が開く; `/news?article={contentId}` の記事の案内の「AI に質問」を押すと、その記事を対象に同じ面が開く; AI チャットの面を閉じると、元の画面（図と記事の案内）がそのまま残っている
- [x] [Frontend] 記事の案内を下から出す面で開いている間に、面の中をスクロールしても後ろの図が動かないようにする。面の中のスクロールは端に着いても後ろへ伝えず（`overscroll-behavior: contain`）、ページ全体も弾ませない。面を開いている間は、後ろの図を指でずらす操作と拡大縮小を受け付けない。図を画面に合わせ直すのは中心の記事が替わったときと出すノードの組が替わったときのうち、記事の案内が関係のある記事を足しただけのときは中心を保ったまま動かさない（BD-03 SCR-002・SCR-003、BD-09 5章、DD-01 M03・M07）（se/08-news-2）
  - 受け入れ基準: 下から出る面（M07 の `BottomSheet`）のスクロールする部分の `overscroll-behavior` が `contain` である; `html` と `body` の `overscroll-behavior` が `none` である; 記事の案内の面を開いている間、図（React Flow）の指でずらす操作と拡大縮小が切られている; 記事の案内の面を閉じると、図を指でずらす操作と拡大縮小が元に戻る; 記事の案内を読んで関係のある記事が図に足されても、図を画面に合わせ直す処理を呼ばない
- [ ] [Frontend] News Galaxy の上の帯から「AI に質問」（SCR-002-A05）を外す。日付（SCR-002-I01）は題名の下に、暗い土台とアンバーの色の選択欄で置く。テーマ（SCR-002-I02）はブラウザの `<select>` をやめ、「すべて」と各テーマを、件数付きの丸い選択ボタンにして横に並べ、入りきらなければ横にスクロールする。並びの先頭に「未読」の切り替え（SCR-002-I03、SCR-002-A06）を置き、選んだ日の記事のうち未読の数を添える。押すと図を未読の記事だけにし、もう一度押すと全ての記事に戻す。テーマの絞り込みと重ね、サーバは呼ばない。見た目は `NEXUS_implementation_handoff/references/news-galaxy-reference.png` と Tailwind の設定の色に合わせる（BD-03 SCR-002、CR-018）
  - 受け入れ基準: 記事を選んでも、上の帯に「AI に質問」が出ない; テーマの選択がボタンの並びで、ボタンに件数が出て、押したテーマの記事だけが図に出る; 「未読」の切り替えに、選んだ日の記事のうち既読でない記事の数が出る; 「未読」を押すと既読の記事のノードが図から消え、もう一度押すと戻る; 「未読」とテーマを両方選ぶと、そのテーマの未読の記事だけが出る; 「未読」を押しても `getGalaxy` を呼ばない; 記事の案内で「読んだ」を押すと、未読の数が1つ減る; 押す場所が全て 44 ピクセル四方以上である
- [ ] [Frontend] 記事の案内（SCR-003）を下から出す面を暗い面（M07 の `BottomSheet` の `tone="hud"`）にし、`NEXUS_implementation_handoff/references/news-galaxy-reference.png` の下の面に合わせて、画像を左、テーマと届いた日時と見出しを右に置き、関係のある記事を小さい画像付きの行にする。「読んだ」「未読に戻す」は本、「保存」「保存を外す」はブックマーク、「AI に質問」は吹き出しのアイコンのボタンにし、ボタンの名前（`aria-label`）は BD-09 4章の操作の言葉にする。既読のときは本のアイコンを、保存しているときはブックマークのアイコンを塗る。全画面で開いたとき（`/news?article={contentId}`）も同じ見た目にする。アイコンは SVG で部品の中に書き、外から読み込まない（BD-03 SCR-003、BD-09 4章、DD-01 M03・M08、CR-018）
  - 受け入れ基準: 記事の案内の面が `tone="hud"` で出る; 既読・保存・AI に質問のボタンに文字が無く、ボタンの名前がそれぞれ「読んだ」か「未読に戻す」、「保存」か「保存を外す」、「AI に質問」である; 既読の記事では本のアイコンが塗られ、未読では塗られない; 保存した記事ではブックマークのアイコンが塗られ、保存していない記事では塗られない; 操作に失敗したときの MSG-003 の操作の名前が今と変わらない; 灰色の文字（`text-gray-*`）を使っていない; 押す場所が全て 44 ピクセル四方以上である
