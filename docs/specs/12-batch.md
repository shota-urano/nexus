# 12. バックアップと古い記録の削除 仕様

**親**: [`00-overview.md`](./00-overview.md) ｜ **担当**: Backend ｜ **範囲**: 定期ジョブの入口（M27）、BAT-001（FN-021）、BAT-002（FN-022）

設計の正本は `docs/upstream/` の上流工程の書類である。この仕様書は、DD-11 実装単位一覧が書き出した実装への引き渡しで、設計の中身を書き写さず、書類と節で指す。

## 1. 目的

毎日のバックアップと、月に1回の古い記録の削除を作る。

## 2. 入出力

入力: 起動の引数（`backup`、`purge`）。出力: 写しのファイル、ログ、終了コード。

## 3. 処理詳細

- DD-02 FN-021、FN-022。
- 多重起動と再処理: DD-05 4章。
- 消す順: DD-03 2.3。

## 4. 設定値・確定値

- BAT-001 は毎日 3:00、BAT-002 は毎月 1日の 3:30（BD-02 5.1。CR-012）。
- 写しは 7 日分、権限は `0600`（BD-02 5.3、NFR-028）。
- 終了コードは 0、1、2（BD-02 5.4）。

## 5. インターフェース

`node dist/jobs/main.js backup|purge`（DD-09 2.6）。

## 6. エラー処理

DD-06 E08、E14、E15、E16。MSG-038〜MSG-041。

## 7. スコープ外

launchd の設定（13-release.md）。
