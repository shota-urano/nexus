**親**: [`00-overview.md`](./00-overview.md) ｜ **担当**: Frontend ｜ **範囲**: ホームの表示（FN-020）の API と画面（SCR-001）、端末の API のオリジンの確かめの通し

## 1. 目的

ホームに出す数、学習の続き、AI の状況、今日のピックアップ、知らせを返す API と、円形 HUD の画面（M02）を作る。

## 2. 入出力

入力: 無し。出力: DD-04 `getHome` の応答と画面。

## 3. 処理詳細

- DD-02 FN-020。
- 未着と失敗の決め方: BD-11 M01、M02（Q-078 の答え）。

## 4. 設定値・確定値

- 未着は日本時間の 7:00 から出す（NFR-022）。
- 失敗は直近 24 時間で、自動の送り直しで完了したものは数えない（Q-078 の答え）。
- ピックアップは関係の数の多い順に 3 件（Q-037 の答え）。
