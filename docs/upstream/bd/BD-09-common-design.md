## 3. 共通コード

コードの値と意味は BD-07 4.2 を正とし、この書類には書かない。画面に出すときの決まりは次のとおり。

- コードの値は画面に出さず、意味の名前を出す（例: 関係の種類は「続報」「背景」のように出す）。採点は ○、△、× の記号で出す。
- 届いた内容の種類（ニュース、英語、これから足す種類）は、一覧の行に名前と色の印で出す。色は種類ごとに1つに決め、BD-03 で決める。
- 関係の種類は BD-07 4.2 の4つの値だけを残す（AI がほかの言葉を返したときの扱いも BD-07 4.2）。画面には名前（続報、背景、共通の主体、関連する話題）を出す。

## 4. 命名規則

| 項目 | 決まり |
|---|---|
| 画面名・機能名の付け方 | 画面名は RD-07 の名前を使う。ホームの7つの機能は依頼 2章の英語の名前（News Galaxy、English、Inbox、Explore、Library、AI Chat）と Research（CR-020）を画面にそのまま出す。機能名は「対象＋動作」（例: 記事の案内の表示）にし、RD-05 の名前を使う |
| データ項目名（論理名）の付け方 | X-03 の語を使い、同じ意味には同じ名前、違う意味には違う名前を使う。記事の分類は「テーマ」、英語のセットの題材は「学習テーマ」と分ける（X-03）。1つの項目に2つの意味を持たせない（例: 新着と未読を1つの項目にしない。RD-03 R18） |
| 操作の言葉 | 次の表のとおり揃える |
| 用語集との関係 | 名前に使う語は X-03 に載っている語に限る。載っていない語を使うときは、先に X-03 に足す |
| アイコンのボタン | ボタンをアイコンだけで出すとき（SCR-003 と SCR-011 の読んだ、保存、AI に質問。CR-018、CR-020）は、下の表の操作の言葉をボタンの名前（`aria-label`）にし、MSG-003 の操作の名前にも使う |

| 操作 | 画面に出す言葉 | 使い分け |
|---|---|---|
| 既読にする | 読んだ | 記事と週報の既読（RD-03 R05、R24）。教材は完了で既読になり、この操作を出さない |
| 未読に戻す | 未読に戻す | 既読の内容を未読にする（Q-044 の答え） |
| 保存する・外す | 保存、保存を外す | 保存の状態で入れ替えて出す（RD-03 R20） |
| 完了する | 完了 | 英語の教材の採点の段で使う（RD-03 R10） |
| やり直しを置き換える | 置き換える | MSG-006 の確認でだけ使う |
| 質問を送る | 送る | AI チャットの質問 |
| 送り直す | 送り直す | 失敗した応答か、止めた応答を同じ質問で送り直す（RD-03 R15） |
| 応答を止める | 止める | 作っている途中の応答を止める（RD-06 UC-014） |
| 失敗をそのままにする | やめる | 失敗した応答を送り直さない（RD-06 UC-014）。確認の面で選ばないときにも使う |
| 新しい会話を始める | 新しい会話 | 前の会話を選ばずに始める（RD-03 R14） |
| 質問する | AI に質問 | 記事、教材の語句と文、図のノードから AI チャットを開く入口 |

## 5. 共通UIルール

RD-07 3章の画面設計方針を参照し、ここには書き写さない。基本設計で足す決まりは次のとおり。

| 項目 | 決まり |
|---|---|
| 画面の領域の分け方 | ホーム（SCR-001）は、左の円形 HUD と右のカードの2つの領域にする（RD-07 SCR-001）。ほかの画面は、上の帯（ホームへ戻る、画面名。内容を開いている画面では AI チャットを開く入口も。BD-03 4章、CR-003）と本文の2つにする。上の帯のホームへ戻る操作は、ホームと同じ NEXUS のロゴにする。上の帯は、端末の上端の安全な余白（`safe-area-inset-top`）と、iPad のホーム画面のアプリのウィンドウの操作ボタンに隠れないよう、ホームの上の余白と同じだけ下げる（CR-018）。AI チャット（SCR-006）と記事の案内（SCR-003）は、本文に重ねて下から出る面にする。iPad でも AI チャットは下から出る面にする（BD-13 P04。2026-11-24 本人。BD-03 SCR-006） |
| ナビゲーションと遷移のパターン | ホーム → 機能の画面 → 一覧 → 詳細 の型にする（RD-07 3章）。戻る操作は1つ前の画面に戻る。下から出る面は、閉じると元の画面に戻る。ホームの選ぶ操作（HUD を回す）と移る操作（カードを押す）は分ける（BD-13 P01。2026-11-24 本人） |
| 一覧の決まり | 一覧（SCR-004、SCR-007、SCR-008、SCR-009）は新しい順に並べ、下までスクロールすると続きを読み込む。1回に読む件数は、NFR-001 の2秒に収まる数を DD-04 で決める。ページ番号は出さない。並び替えの切り替えは置かない（RD-05 に並び替えの機能が無いため）。Explore の検索の言葉は、画面を離れて戻ったときに残す |
| 表示書式 | 日付は、今年なら「11月23日（月）」、今年でなければ「2025年11月23日」にする。時刻は24時間で「05:30」にする。一覧（SCR-004、SCR-007〜SCR-009）には時刻を出さず、日付だけを出す（BD-13 P06。2026-11-24 本人）。新着はタグで出す。件数は桁区切りを付けない数字にする（1日50件までで4桁にならないため）。金額とマイナスの値は出さない。この書式は BD-13 で本人が確かめた（2026-11-24） |
| 誤操作の防止 | 確認を出すのは、完了した教材をやり直して前の答えを置き換えるときだけにする（RD-07 3章、MSG-006）。二重送信を防ぐため、「送る」「完了」「送り直す」は、押してから結果が出るまで押せなくする |
| セッション切れ | 時間で切れるログインは持たない（端末の鍵を長く使う。BD-01 6章）。端末の鍵が取り消されたあとに開くと、MSG-020 を出す。入力の途中の値は消える |
| 対応する環境 | RD-11 NFR-007 による |
| アクセシビリティ | 準拠する基準は無い（RD-07 3章）。押す場所は44ピクセル四方以上、端末の動きを減らす設定に従う（RD-11 NFR-008）。動きを減らす設定のときは、HUD の回転とカードの移動と図の動きを、動かさずに切り替える |
