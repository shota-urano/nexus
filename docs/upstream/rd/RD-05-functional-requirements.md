## 2. 管理用機能の確認

| 分類 | あるか | 中身 |
|---|---|---|
| アカウントの管理 | 無 | 利用者は本人だけ（Q-004 の答え）。端末の認証と配信元の鍵は、本人が Mac mini の NEXUS の設定で用意し、取り消す（Q-034 の答え）。画面は持たない |
| マスタの更新 | 該当なし | 画面で更新するマスタは無い。情報の種類を足すときは、新しい種類の表示部品が要る（依頼 1章 設計原則2）ので、プログラムの変更で足す |
| バッチの実行 | 有（画面なし） | FN-021 と FN-022 を Mac mini の定期実行で動かす（Q-050 の答え）。手で動かすときは本人が Mac mini で動かし、画面は持たない（Q-034、Q-036 の答えと同じ扱い） |
| ログの記録と検索 | 有（画面なし） | AI の実行の記録（監査ログ。依頼 7章）と配信の受け取りの記録を残す。画面は持たず、本人が Mac mini のログで見る（Q-036 の答え） |
| データの出力・取り込み | 該当なし | CSV などのファイルで取り出す機能は持たない。要るときはバックアップから取り出す（Q-055 の答え）。これまでの情報の取り込みもしない（Q-011 の答え） |

## 3. 機能構成図

機能が30件を超えないので描かない。

## 4. 機能ごとの規模

- 件数・回数: FN-021 は1日1回、FN-022 は月に1回（Q-050 の答え）。届く内容は全ての種類を合わせて1日50件まで、AI への質問は1日10回（RD-03 4章）。ニュースは毎朝5時、英語は毎朝5時半にまとめて届く（RD-03 4章）。FN-002 が1件の記事について照らす記事は、7日前までの記事（RD-03 R02）。

## 5. 上流との対応

各 FN の根拠 REQ、該当業務 BIZ、関連ユースケース UC は1章の表の列に書いた。

- RD-16 の機能の要件 REQ-001〜REQ-018 と REQ-026 は、全てどれかの `FN` に対応する。
- RD-04 の UC-001〜UC-018 は、全てどれかの `FN` に対応する。
